Important notes

Keep inferenceProvider: bedrock and the approved Syncoria IAM Identity Center settings unchanged. Do not put API keys, passwords, or employee Google tokens in public configuration. Settings are public; access to AWS and Google remains governed by the employee's own login.

Automatic skill installation is a separate function. Publishing the JSON does not copy skill files onto employees' PCs.
