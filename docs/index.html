Employee onboarding

Four simple steps

1

Install Claude Desktop

If you have Claude Desktop already, go directly to Step 2.

Download Claude ↗
2

Apply Syncoria settings

Download the company configuration. Double-click the .reg file and approve the Windows prompt. This switches your computer from the old Lambda configuration to GitHub Pages.

Download company settings ↓
3

Restart Claude, then sign in with AWS

Quit Claude completely (including the system tray) and reopen it. Select Sign in with AWS using your company account.

4

Connect your Google Workspace account

When requested, authorize Google Drive, Docs, Sheets and Slides with your own work identity. File access is never shared automatically with colleagues.

All future configuration updates will be published through GitHub and pulled through your existing Windows policy URL. You do not have to reinstall the policy after every settings change.
Configured capabilities

  • ✓ Company AWS Identity Center sign-in

  • ✓ Tool search and Claude.ai import options
  • ✓ Business profile without developer tooling
  • ✓ Plugins available through approved marketplaces

Syncoria skills are packaged on every GitHub push. To make them appear automatically on a computer, the package must also be installed via a supported plugin mechanism. A GitHub Pages configuration URL alone does not install them.

Administrator settings and migration

The public bootstrap is a version-controlled JSON file. Only authorized GitHub contributors can change it. Publishing is done through GitHub Actions; there is no shared admin password on this website.

Open the Settings guide ↗ · View current JSON ↗ · Deployment history ↗

Migration: Every existing PC still pointing to the AWS Lambda URL must apply the new .reg file once before the old Lambda is decommissioned.
